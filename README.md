# Team Building Game

Branching-scenario eLearning course built in **Articulate Storyline** by **Anupam Sarkar**.

Learners lead a myth-inspired Pandava mission, practice **Tuckman’s team stages** and **Belbin team roles**, make decisions across four challenges, and finish with one of four outcomes—Victory, Narrow Escape, Retreat, or Defeat—plus a completion certificate path.

- **Play (GitHub Pages):** [https://anupamsarkar-courses.github.io/team-building-game/](https://anupamsarkar-courses.github.io/team-building-game/)
- **Source branch for the live site:** `gh-pages`
- **Launch file:** `story.html`
- **Duration:** about 5–9 minutes
- **Built with:** Articulate Storyline (HTML5 publish, audio narration, closed captions)

Published package is rebuilt from `chunks/` on each push to `main` via GitHub Actions.
