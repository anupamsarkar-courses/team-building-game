# Team Building Game

Branching-scenario eLearning course built in **Articulate Storyline** by **Anupam Sarkar**.

Learners take on a myth-inspired team mission, make decisions across four challenges, and finish with one of four outcomes—Victory, Narrow Escape, Retreat, or Defeat—plus a completion certificate path.

- **Play the course:** [Open Team Building Game](https://anupamsarkar-courses.github.io/team-building-game/)
- **Launch file:** `story.html`
- **Duration:** about 9 minutes
- **Built with:** Articulate Storyline (HTML5 publish, audio narration, closed captions)

This repository hosts the published HTML5 package on GitHub Pages.
